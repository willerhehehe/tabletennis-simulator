# 乒乓策略玩法 demo · v0.5.1

零依赖浏览器游戏，与 Unity 物理试验场独立。支持单人对电脑与同机双人交接。

```sh
cd /Users/willer/workspace/willer-project/tabletennis/strategy-demo
python3 -m http.server 8879 --bind 127.0.0.1
```

打开 http://127.0.0.1:8879 。第一次建议从首页的「短下旋接发」情景开始。

## 本版操作

1. 选均衡、正手突击或反手控制打法，直接开始。完整 10 点加点、双人和赛制放在“自定义”中。
2. 点场地选择发 / 接发站位；也可直接“就在这里”。
3. 来球时点“抢正手 / 抢反手 / 再看一拍”，立即完成预判。场上先给出建议位置，可以提前改格子。
4. 回球时用动作卡选招式，自动预览一个预算内的就位位置；可以手动微调。
5. **点对方半台直接击球**。鼠标悬停或键盘聚焦可预览线路；没有“确认回球”按钮。

旋转改判、用手、还原与概率放在展开区域。常用四招直接显示，其他技术在“更多接法”中；选择其他招后会进入常用栏。手机上动作栏固定在下方，方便对着球台操作。

就位建议只读当前角色可见信息，不知道真实旋转或对手能力；也不会替玩家挑选战术。看清后快球最多补一步、慢球两步。预算耗尽时无法免费换手，无法够到的站位会明确提示。

球长、速度、旋转与高度依然按具体技术结算；本次主要改变交互流程。三局两胜或五局三胜，净胜两分，平分延长后逐分换发。刷新重开。

## 验证与研究

```sh
node check.mjs
node balance.mjs > balance-results.json
```

- `game.mjs`：技术、信息投影、状态转换、概率和电脑策略。
- `court.mjs` / `index.html`：俯视球台、动作卡和直接击球。
- `controls.mjs`：不读取秘密状态的就位建议。
- `motion.mjs`：移动、击球与网前来球的短动画；遵循减少动态效果偏好。
- `RULES_RESEARCH.md`：乒乓球资料、条件矩阵与修订前的问题。
- `DESIGN_NOTES.md`：趣味性研究、具体设计、验证与真人试玩问题。
- `balance-results.json`：最近一次策略探针结果，具体版本见文件内 version，不是真人体验证明。

电脑只读取 `view()`，不会读取隐藏技能或真实旋转。可导出已经完成的回合与公开记录，排除技能加成、内部阈值和未完成的击球方案。记录支持审阅动作，暂不支持确定性重放或恢复存档。

本版反胶模型覆盖主要技术关系；侧旋连续偏移、更多胶皮与特殊动作尚未实现。仅本机试玩，无账号、联网与防作弊；刷新重置比赛。数值未经真人平衡验证。

当前 v0.4 针对“不够好玩”的反馈试验：去掉不影响规则的落点行选择，直接标出对手侧别与横向距离；看清后快球最多补一步、慢球两步，使提前移动产生实质收益。该时间窗口是桌游规则试验，不是真实时间标定。

出手后会播放短动画，无需额外确认。对方预判阶段的动画仅到球网附近，不显示真实终点；动画期间锁定输入避免重复出手。单人模式得分后保持 A 在下方，并显示得分提示。
