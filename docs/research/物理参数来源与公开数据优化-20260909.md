# 物理参数来源与公开数据优化

核查日期：2026-09-09。本文是来源审查与优化方案，没有修改默认系数，也没有声称完成实测拟合。

## 当前参数

当前代码的依据分为规格、物理近似、未标定经验初值与数值求解设置。README 已注明默认空气与接触系数不是某款器材的实测结果。

| 项目 | 当前值 | 来源性质 |
|---|---|---|
| 球直径、质量 | 40 mm、2.7 g | 标准规格；实际球有制造差异 |
| 球转动惯量 | 2mr²/3 | 理想均匀薄球壳近似 |
| 重力、空气密度 | 9.81 m/s²、1.225 kg/m³ | 常用环境初值，未根据现场温度气压调整 |
| 空气阻力 Cd | 0.47 | 球体经验初值，未按乒乓球速度与旋转拟合 |
| 升力曲线 | slope=0.6，cap=0.35 | 未标定的单调饱和曲线 |
| 旋转衰减 | 0.08 /s | 未标定指数衰减 |
| 球台恢复、摩擦 | e=0.88，μ=0.20 | 未标定经验初值 |
| 胶皮法向恢复、摩擦、切向恢复 | e=0.8，μ=0.8，β=0.15 | 未标定经验初值；不对应具体胶皮或海绵硬度 |
| 积分步长 | 0.001 s | RK4 数值精度设置，不是器材参数 |

胶皮模型使用瞬时碰撞冲量：法向冲量 Jn=−(1+e)m vn；切向冲量以相对滑动速度为基础，并受 μJn 限制。β 控制切向恢复目标。未显式求解海绵压缩、粘弹性或接触力随时间变化，因此不能将其称为已经标定的胶皮弹性模型。

## 可以利用的公开依据

### 1. 球拍碰撞原始数据：优先用于接发研究

- 论文：Thomas Gossard, Learning Racket-Ball Bounce Dynamics Across Diverse Rubbers for Robotic Table Tennis, 2026（预印本）。
- https://arxiv.org/abs/2604.11349
- 作者仓库：https://github.com/gossardt/tt_rackets
- 仓库 MIT License 已读取。目录包含 10 种球拍配置的 original/train/test CSV，README 列明胶皮、底板、海绵厚度。
- 已实际读取 racket_01 的训练集 794 行、测试集 199 行。字段含 racket_angle、spin_before/after_x/y/z、v_in/out_x/y/z。
- 拟合前仍须核对作者坐标变换、转速单位、拍面参考系、样本筛选方式和实验覆盖区间；不能直接把列名当成本项目世界坐标。
- 先拟合每种器材的有效法向恢复和切向响应，再比较分段函数是否优于常数。仅凭抓持区样本未必能识别唯一 μ，应报告可识别性或有效响应参数。
- 固定训练/测试划分，测试集不用于调参；分别报告出球线速度、旋转误差与改善幅度。最终还需检查整条球路的落点误差。

### 2. 气动力与球台模型：有公开参数表

- Sony AI: Physics Models for Sim-to-Real Transfer in Professional-Level Robot Table Tennis, 2026（预印本，读取 v2）。
- https://arxiv.org/html/2606.28805v2
- 表 I 给出多个参考速度与旋转比下的 Cd 表；例如 2.5 m/s 档为 0.55，12.5 m/s 档随旋转比变化，包含 0.41–0.53。这说明把所有情况固定为 0.47 是较粗近似。
- 表 II、III 给出 CM 分段拟合参数，可实现论文参考档并按参考速度插值。
- 注意 CM 与本项目 Cl 的定义不同：论文 FM=CM ρ V (ω×v)，本项目 |FM|=ρ A Cl v²/2。若 S⊥=r|ω×v|/v²，则两者等价转换为 Cl=(8/3)CM S⊥。不得直接替换系数。
- 论文球台基准 μ=0.25，恢复系数依赖法向速度，并另有残差修正。只复制一个常数无法复现完整论文模型。
- 论文使用特定球、台与胶皮，公开参数可作为有来源的参考模型，不能把论文误差数值直接当成本项目精度。

### 3. 球台材料实验与基础规格

- Inaba 等，2017：Effect of Changing Table Tennis Ball Material from Celluloid to Plastic on the Post-Collision Ball Trajectory。
- https://pmc.ncbi.nlm.nih.gov/articles/PMC5304273/
- https://johk.pl/?p=4098
- 比较球材料和入射条件对恢复、摩擦及后续轨迹的影响，可用于检验单一常数的局限。当前会话全文抓取遇到验证页，未据此抄录回归系数。
- ITTF 2023 官方规则：标准台面从 30 cm 落球约弹起 23 cm；忽略空气阻力与高度口径细节时 e≈√(23/30)≈0.876。这里只说明当前 0.88 在低速反弹数量级上合理，不是其原始实测来源，也不能外推到高速或带旋碰撞。
- https://db.ittf.com/sites/default/files/public/2023-09/2023_ITTF_Statutes_clean_version2_2023-09-01_2.pdf

### 4. 独立飞行/弹台数据

- 作者代码与数据说明：https://github.com/EmbodiedVision/tabletennis-spin-impacts
- 包含位置轨迹、帧索引、碰撞索引及数据划分；README 区分到达时间与拍摄帧时间。
- 数据、模型的使用许可应按其 archive-metadata.md 分别核对。它与球拍碰撞数据职责不同；不能用发球机转速直接当球的实际转速。

## 推荐落地顺序

1. 保留现有经验模型作为对照，将它明确标为“未标定”。
2. 增加可切换的“论文气动力/球台参考档”，记录论文版本、器材与有效区间，完成系数定义转换及边界测试。
3. 用公开球拍数据建立器材分档，先做有独立测试集的简单拟合，再决定是否需要更复杂模型。
4. 对不同模型重复同一批接发实验，显示接法排名对材料参数的敏感性，防止搜索利用模型误差。
5. 以目标器材的少量实测数据作最后校正。厂商速度/旋转评分与海绵硬度不能直接转换成 μ、e、β。
