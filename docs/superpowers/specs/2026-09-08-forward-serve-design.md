# 直线挥拍发球

用户已选择：落球高度、拍面与台面的夹角（0°水平）、挥拍起终点、启动时刻与时长；真实相交才击球，漏球应明确显示。

首版从无旋球的抛球顶点开始，省略手的上抛过程。固定拍面姿态，球拍沿两点之间匀速移动，路径前后静止。模型检测有限椭圆胶皮与球的连续相交，复用现有摩擦冲量求出速度和旋转，再复用飞行、球台和球网碰撞。柄和拍边击球、胶皮形变、手臂可达性不在首版内。可能碰台的挥拍不能送入接发研究。

界面新增「挥拍」入口，保留直接设定出球和接发研究。默认展示落球、球拍路径和出球完整轨迹，支持旋转缩放、慢放、停在触球及触球放大。可从计算得到的发球继续选接球点。正面黑、背面红。角度名称区分拍面与出球，文字以 Retina 逻辑尺寸放大。

落台数据展示每次碰撞前后的速度、三轴旋转分量与球台摩擦系数；标明经验系数尚待实测。

验收：近水平拍底摩擦能生成下旋；零摩擦不生旋；漏球不生成假出球；前后两面能碰撞；步长减半时触球和落点收敛；球台摩擦同时改变线速度和角速度；0/40/90°拍型与显示法向一致；真实点击、拖动、慢放在 Retina 下正确；接发研究沿用实际发球结果。

参考：Hayakawa 等，Ball Trajectory Planning in Serving Task for Table Tennis Robot，SICE JCMSI 9(2), 2016, DOI 10.9746/jcmsi.9.50。已阅读学会摘要 https://www.sice.jp/pub/vol9no2.html ，全文抓取返回 403。摘要支持建模顺序，不能作为本项目摩擦系数或实际精度的标定依据。
